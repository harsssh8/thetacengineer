The TAC Engineer — Technical Publication Site

Design and build of this site: a static, dependency-free technical publication hosted on Cloudflare Pages.

Project·Nov 2026·4 min read·In Progress

On this page

    Status
    In Progress
    Type
    Web / documentation
    Hosting
    Cloudflare Pages (free plan)
    Source
    GitHub

    01Problem or objective

    Build a professional, low-maintenance place to publish technical articles, lab write-ups and troubleshooting case studies. Requirements: no hosting cost, no server to patch, fast on mobile, and easy to extend by editing files in Git.

    02Architecture

    The site is plain static HTML, CSS and a small amount of JavaScript. A single data file (assets/js/content.js) lists every article, lab, case and project. The homepage, listing pages, search, related articles and previous/next links are all generated from that file in the browser.

    03Technologies

    • HTML5
    • CSS (custom properties, grid)
    • Vanilla JavaScript
    • Git / GitHub
    • Cloudflare Pages
    • Inline SVG diagrams

    04Implementation

    • Design system defined with CSS custom properties: navy and blue palette, Inter typeface, consistent cards and documentation components.
    • Documentation layout with an auto-generated table of contents, code blocks with copy buttons, callouts, tables and figures.
    • Honest status labelling for labs and a visible Demo badge on demonstration content.
    • Security headers and clean URLs configured through Cloudflare Pages' _headers file.

    05Testing

    • Layouts checked at desktop, tablet and mobile widths.
    • Text colours chosen to meet WCAG AA contrast on light and dark backgrounds.
    • Keyboard navigation and visible focus states for all interactive elements.
    • To add after launch: Lighthouse scores and real-device checks.

    06Results

    To be updated after the site goes live on its custom domain.

    07Documentation

    The repository README explains how to deploy to Cloudflare Pages, connect a custom domain, and publish new articles, labs, cases and projects.
